# dashboard-vendas

Este projeto tem como objetivo a criação de um dashboard de vendas no Excel, transformando dados brutos em informações visuais claras e úteis. O foco está na organização e visualização de dados para facilitar a análise do desempenho de vendas e auxiliar na tomada de decisões estratégicas.

## Arquivos

- `base.xlsx`: Base de dados bruta utilizada para a criação do dashboard.
- `dashboard_final.xlsx`: Arquivo Excel contendo o dashboard concluído.

## Como Reproduzir

1. Clone este repositório ou baixe os arquivos.
2. Abra o arquivo `dashboard_final.xlsx` no Microsoft Excel.
3. Explore os gráficos e filtros interativos presentes no dashboard.

## Sobre os Dados

A base de dados contém informações como:
- Data da venda
- Produto
- Plataforma
- Quantidade vendida
- Receita
- Região
- Tipo de cliente

## Funcionalidades do Dashboard

- Filtros dinâmicos por data, produto, plataforma e região.
- Gráficos de desempenho mensal.
- Receita total e quantidade de unidades vendidas.
- Comparativo entre plataformas (ex: Xbox, PlayStation, etc.).

## Ferramentas Utilizadas

- Microsoft Excel (com Tabelas Dinâmicas e Gráficos)
